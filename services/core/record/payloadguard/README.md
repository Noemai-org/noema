# record/payloadguard

The write-side guard of the Record (A184, A193, A194, A201) and the one definition of a run of digits.

- **What it does.** `Check` refuses a payload whose strings hold a run of more than `Limit` (4) digits, with typed exemptions (A193). `Mask` keeps only the last `Limit` digits of every run of a string; `record/reconstruct` serves its facts through it and keeps no regexp of its own (A194).
- **One definition, one set (A231, interim).** `separators` is the one set that joins digits: every kind of space (`\p{Z}`, the vertical tab, the four ASCII information separators U+001C to U+001F added by A308, the next-line character), every dash (`\p{Pd}`) and the minus sign, every bracket (`\p{Ps}`, `\p{Pe}`), the dot, slash, colon and underscore with their full-width forms and the middle dots, every format character and every combining mark. A comma is not in it (an amount like `20,000,000` is not one run). The guard refuses by `digitRun` and the display mask masks by the same `digitRun`: there is no second mode, so a number split by an underscore, a colon or a bracket is refused at append and masked on display. **The one exemption, narrowed (A231 as written, then Codex's P1 and the Security Reviewer on noema#600):** the transport class a receipt carries, **at its two exact top-level payload paths and for a finite vocabulary only**: `/transport_result` is one of the adapter's transport classes (`VERSION_CONFLICT_409_412` is the one with digits), and `/raw_status` is such a class, then at most two colon-separated raw-code parts (one to three digits, or an UPPER_SNAKE word with no digit), at most 9 digits in all. The same string at any other path, or a nested `raw_status`, is refused, so no identifier can travel as a "code". `TransportClasses()` is the guard's copy of the controller's `TransportClass` constants; a test reads the controller source and fails when they differ. `Mask` has no path, so it has no exemption: a class with digits is shown partly masked in a served fact. **Deviation from A231 as written (a whole-string UPPER_SNAKE shape anywhere), in the safer direction: for the Architect to confirm.**
- **Money (A279, A270, interim) and the shared vectors (A259, interim).** A string is exempt from the digit-run refusal when the WHOLE string is an amount: `^[A-Z]{3} [0-9]{1,3}(,[0-9]{3})*(\.[0-9]{2})?$` (ASCII only, the end of the string and not before a final newline) with at most nine digits before the point (`isMoney`, in `exempt`, at any path, beside the other whole-string exemptions). Ungrouped digits, ten or more integer digits, another prefix and any other number of decimals stay refused. `Mask` has the money exemption too (A308, interim): a stored `NGN 12,345.00` is served as it is, not `NGN 12,*45.00`; `record/reconstruct` and `explanation/factsource` read it through `Mask`, so an explanation fact for an amount such as `NGN 1,234.50` is now shown (it was an unknown, noema#586). This class is the source of truth for the digit run; `contracts/fixtures/digit_run_vectors.json` is the one fixture that ties it to the model service's redactor (`services/model/noema_model/platform/redaction`) and the UI scan (`ui/src/privacy.ts`). `vectors_test.go` loads it and asserts the verdict of every named vector. The regular expression is repeated in each language; the file is the tie.
- **The limit** equals the one number of `masking-limits.v1` (`TestTheGuardsLimitIsTheMaskingLimitOfThePack`).
- **REQs.** REQ-AUD-003, REQ-SEC-003; A154, A184, A193, A194, A201.
- **Tests.** `go test ./record/payloadguard/ ./record/reconstruct/`. `vectors_test.go` reads `contracts/fixtures/digit_run_vectors.json` (three tests: the file is well formed, `Check` gives every vector's verdict, `Mask` agrees on every vector, the money vectors included, A308).
