# record/payloadguard

The write-side guard of the Record (A184, A193, A194, A201) and the one definition of a run of digits.

- **What it does.** `Check` refuses a payload whose strings hold a run of more than `Limit` (4) digits, with typed exemptions (A193). `Mask` keeps only the last `Limit` digits of every run of a string; `record/reconstruct` serves its facts through it and keeps no regexp of its own (A194).
- **One definition, one set (A231, interim).** `separators` is the one set that joins digits: every kind of space (`\p{Z}`, the vertical tab, the next-line character), every dash (`\p{Pd}`) and the minus sign, every bracket (`\p{Ps}`, `\p{Pe}`), the dot, slash, colon and underscore with their full-width forms and the middle dots, every format character and every combining mark. A comma is not in it (an amount like `20,000,000` is not one run). The guard refuses by `digitRun` and the display mask masks by the same `digitRun`: there is no second mode, so a number split by an underscore, a colon or a bracket is refused at append and masked on display. **The one exemption, narrowed (A231 as written, then Codex's P1 and the Security Reviewer on noema#600):** the transport class a receipt carries, **at its two exact top-level payload paths and for a finite vocabulary only**: `/transport_result` is one of the adapter's transport classes (`VERSION_CONFLICT_409_412` is the one with digits), and `/raw_status` is such a class, then at most two colon-separated raw-code parts (one to three digits, or an UPPER_SNAKE word with no digit), at most 9 digits in all. The same string at any other path, or a nested `raw_status`, is refused, so no identifier can travel as a "code". `TransportClasses()` is the guard's copy of the controller's `TransportClass` constants; a test reads the controller source and fails when they differ. `Mask` has no path, so it has no exemption: a class with digits is shown partly masked in a served fact. **Deviation from A231 as written (a whole-string UPPER_SNAKE shape anywhere), in the safer direction: for the Architect to confirm.**
- **The limit** equals the one number of `masking-limits.v1` (`TestTheGuardsLimitIsTheMaskingLimitOfThePack`).
- **REQs.** REQ-AUD-003, REQ-SEC-003; A154, A184, A193, A194, A201.
- **Tests.** `go test ./record/payloadguard/ ./record/reconstruct/`.
