## Session 2026-11-16 · test first
- A252 approves @axe-core/playwright 4.14.0 and axe-core ~4.14.0 with a lockfile for local scans only. Steward records the decision. The base frontend dependencies are already approved; the manifest overlaps noema#502 and #609 and must be reconciled after those merges.
- The initial test requires the real overlay markup and privacy scanner from noema#502; they are not yet on main. It scans only synthetic local markup and uses system Chrome or Chromium, with no browser download.
- An automated axe pass is not proof of WCAG conformance, keyboard usability, Android webview acceptance or the J1–J8 flows. Those remain outstanding.
- First CI run also caught that the repository requires exact dependency versions: the approved `~4.14.0` range failed its pins check. The manifest now pins `axe-core` to `4.14.0`, within that approved range. A local test-first regression also found that `setContent` did not load the stylesheet; the scan now explicitly loads the built tokens before analyzing contrast.
