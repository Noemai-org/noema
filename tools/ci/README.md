# tools/ci

CI safeguards (PLT-02). Standard library only, except the two pinned scanners.

| Check | Script | Fails when |
|---|---|---|
| Dependency pins | `check_pins.py` | a Go module has no `go.sum`; a Python dependency lacks `==` or hashes; an npm version is not exact or has no lock; a Docker base image lacks a digest; an Action is not a full commit SHA |
| Image file list (R2) | `check_image_files.py` | an image carries files of another service |
| Environment references (R3) | `check_env_refs.py` | a workflow references another area's GitHub Environment |
| Secret names | `check_secret_refs.py` | a workflow reads `secrets.NAME` and `.env.example` does not list `NAME` (a trailing `*` covers a prefix; `GITHUB_TOKEN` is built in; a secret looked up by an expression fails) |
| Leak scanner (SEC-03) | `leakscan.py` | run on logs, traces, API output, stored text, explanations or Record dumps: digit runs of 5 or more, card numbers, secrets, or a seeded canary (REQ-SEC-003). Never prints a value. Not yet run over a benchmark run; SEC-07 wires that A scan that looked at nothing (no files, no lines, an empty canary file, a bad allow file) exits 2; a symlink, a gzip or a non-UTF-8 file is a finding; the fingerprint is a per-run salted HMAC. Known gaps: dot- or slash-split numbers, encoded forms, secrets with no secret word in the name (SEC-07). |
| Cross-scope disclosure and planted leaks on every surface (SEC-07) | `scopescan.py`, `sec07_nightly.py`, `sec07/` | a value of one scope (a tenant, or one principal of a tenant) on a surface of another, found by token (`noema_cross_scope_disclosure_total{surface}`, a must-be-zero counter in the Prometheus text format, every surface kind present, zero included); a leak of any kind on a real surface (`noema_leak_scan_findings_total`). Before every scan the driver plants a canary, an account number, a card number, an `api_key` value, a JWT-shaped value, a bearer token and another scope's token on EVERY surface (logs, traces, API output, explanations, the Record) and requires each to be found; a miss is NOT RUN (exit 3), never clean. A scan that looked at nothing, a missing path, a binary file, a link, a token shared by two scopes or fewer than two scopes is exit 2 or 3, never a pass. Never prints a value. `sec07-nightly.yml` runs the probe every night; the scan of a persistent target's real surfaces is the next slice |
| Persisted checkout credential (PLT-05) | `check_checkout_credentials.py` | any `actions/checkout` step under `.github/` lacks `persist-credentials: false` in its own `with:` block. Reads the PARSED YAML (`yamlload.py`, PyYAML `safe_load`, OD-P-95/A283), so a quoted key, a flow mapping, a JSON-style step or an escaped key is judged as what it is; the value must be the boolean `false` (the string `"false"` is the same input); an expression or anything else does not count; an `INPUT_PERSIST-CREDENTIALS` variable on the step is refused; a file that is not plain YAML (an anchor, an alias, a repeated key, a second document) fails; no exemption list |
| Tushe administrator credential | `check_no_admin_in_workflows.py` | any YAML under `.github/` names the Tushe administrator secret or Environment, in any case or separator spelling, comments included (SEC-02, OD-16) |
| PR trace | `check_pr_trace.py` | the PR body lacks a task ID, a PERD `REQ-` ID or a SoT ID; or it starts a `CONFLICT DETECTED` block (a line of exactly that text) and a field of PERD REQ-AGT-003 is missing, empty or still the template placeholder (AGT-01). A body with no marker is not checked for conflicts: the check cannot tell that an agent should have raised one. Tests: `test_check_pr_conflict.py` (not yet run by `safeguards.yml`, which needs a Founder and SR edit); the canary `pr_trace_conflict_without_fields` runs in CI |
| Secret scan | gitleaks via `gitleaks_range.py`, config `/.gitleaks.toml` | a secret is found in the commits of this change: a pull request's `base..head`, or what a push adds (not every ref; the range is printed). `test_gitleaks_range.py` runs it against the real gitleaks |
| Workflow permissions (REQ-SEC-007) | `check_workflow_permissions.py` | a workflow has no top-level `permissions:` mapping; top-level `contents` is not `read` or `none`; any `permissions:` block grants `write` outside `ALLOW_WRITE` (two reviewed issue filers) or holds a value other than `read`, `write`, `none`; a workflow uses `pull_request_target` or a permission block names `id-token`; a block is a scalar (`write-all`, `read-all`) or empty; an `ALLOW_WRITE` entry is no longer used. Reads the PARSED YAML (`yamlload.py`, OD-P-95/A283), so no spelling hides a block; a file that is not plain YAML (an anchor, an alias, a repeated key, a second document) fails |
| YAML parser (OD-P-95) | `yamlload.py`, `requirements.lock` | the one third-party dependency of `tools/ci`: PyYAML 6.0.3, hash-pinned (the CPython 3.13 manylinux wheel), installed in the `safeguards` job only with `--require-hashes --only-binary=:all: --no-deps`, `safe_load` semantics only (a `SafeLoader` subclass that also refuses a repeated key). The two workflow checks fail, not pass, when it is missing |
| SBOM | syft (CycloneDX JSON) | uploaded per image as an artifact |

`run_canaries.py` proves each check can fail. Each canary must fail for its own reason. Canaries are left out by pointing each check at its own canary, never by weakening a check. The fake secret is built at run time.

`install_tools.sh` downloads gitleaks and syft from pinned releases and verifies their SHA-256.

The `codegen-diff` job in `safeguards.yml` is disabled (`if: false`) until CON-03.

**Not enforced yet: oracle and fixture secrets only in `bench`.** No oracle or fixture credential has been issued, so `.env.example` lists none and the check lets no job read one. When the credential is issued, add its name to `.env.example` and the bench-only rule (a job-aware check that reads the workflow with a YAML parser and allows the secret only in a job with `environment: bench`) in the same pull request. That version was built and tested in commit `803e027` of noema#29 and is in its history.
